# Imágenes faltantes · por hojas de 3×3

Faltan **57 palabras** (59 apariciones). Están agrupadas en **7 hojas** para que se puedan generar
igual que las anteriores y se importen sin ambigüedad.

---

## Cómo pedirlas

Para cada hoja, usa este prompt (cambia solo la lista de objetos):

```text
Flat vector illustration sheet for a children's English app, 3x3 grid of nine separate
objects on a plain white background, cute preschool style, thick dark outline (#2B2D42),
bright saturated flat colors, one object centered in each cell, generous margins between
cells, no text, no letters, no numbers, no people, no watermark, square 1:1.
Objects, in reading order: [LISTA DE LA HOJA]
```

**Requisitos del archivo:**
- 1024×1024 px, JPG o PNG.
- **Sin etiquetas de texto** (en las hojas anteriores el texto obligaba a recortar y a veces se comía el dibujo).
- Nombre del archivo: el que indico en cada hoja (`25_...jpg`, `26_...jpg`, …).

Cuando las tengas en `img-ia`, avísame: las recorto, las mapeo y reconstruyo el APK.

## Lo que **no** hay que generar

**54 palabras se quedan con emoji a propósito.** Son saludos, emociones, gramática y palabras
abstractas: buscar o dibujar imágenes para ellas confunde más que ayuda (un pájaro para *hello*).

```
hello, hi, goodbye, bye-bye, good morning, good afternoon, happy, sad, angry, sleepy,
hungry, thirsty, fine, please, thank you, sorry, name, like, don't like, love,
was, were, went, came, will, won't, can, can't, how many, count, maybe, perhaps,
sure, of course, in, on, under, where, next to, between, behind, in front of, near,
opposite, turn left, turn right, go straight, o'clock, half past, today, tomorrow,
yesterday, last night
```

*(Algunas ya tienen ilustración —`in`, `on`, `please`…— y por eso no están en la lista de faltantes.
Esta enumeración es solo para que no gastes generaciones en ellas.)*

## Recordatorio de estilo

Las que ya funcionan comparten esto: **un solo objeto, centrado, contorno oscuro grueso, colores
planos saturados, fondo blanco, sin texto y sin personas realistas**. Las de verbos que incluyen
niños funcionan bien si el niño es **estilo dibujo plano** (como las hojas 16 y 17).
